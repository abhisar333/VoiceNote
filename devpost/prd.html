VoiceNote — PRD Visual review companion. Scope said "a note with replayable voice segments" — now it's a screen, a journey, and checkable behavior.

A single-note screen where talking becomes a grey, replayable bubble of text — read to find your piece, long-press any word to hear that exact spot, and flip to edit mode to fix or extend the note.

Core Journey

Behaviors & States

Capture — the red record button
  • One round red button, bottom right. Tap to start, tap to stop — no separate stop control.
  • Pulses only while the mic hears sound; silence = no pulse (also the "is the mic alive" indicator).
pulsing only while it hears you
Transcription — after you stop, not live
  • Runs on the finished recording, not live while talking (removes the concurrent-mic risk).
  • New grey bubble shows an animated 1-2-3 dot; the user keeps using the app meanwhile.
  • Silent recording → no segment added; a "no audio recorded" notice appears instead.
  • Unconfirmed: if conversion fails (audio present, no usable text), the bubble stays with a "transcription unavailable" message, audio kept, replay still works.
converting…
Replay in place — word-precise
  • View mode only. Long-press any word in a voice bubble.
  • Haptic vibration marks the start; audio starts at that word (not the segment start).
  • Circular progress ring animates at the top-left of the screen.
  • Release the finger → playback stops immediately. Ends on its own at the end of the audio.
  • Unconfirmed: long-pressing while a playback is running stops it; nothing new starts until a fresh press.
Modes — view & edit
  • Toggle at top right, fixed position for the POC (movable is Later).
  • View mode: read; long-press a voice-bubble word to replay. Nothing else.
  • Edit mode (default on open) — an empty note shows its blinking cursor:
    • Tap any segment's text to edit it in place; saving is permanent.
    • Tap empty space → cursor → type → a new typed segment in the note's flow.
  • Editing a voice bubble's text never changes its audio.

Look and Feel

Voice bubbles: grey, rounded edges, matte and "almost transparent but not quite." Typed segments: plain note text.

Record button: round, red

Top-right: the view/edit toggle. Top-left: progress ring during playback.

What "Working" Looks Like — checkable on a real Android phone, under a minute

  1. Open the app → one note, blinking cursor, red round button visible.
  2. Tap it, talk → button pulses while you speak.
  3. Tap again → grey bubble with the 1-2-3 dot appears.
  4. Transcript text fills the bubble.
  5. View mode; long-press a word mid-sentence → vibration, audio from that word, top-left ring, release stops it.
  6. Edit mode; fix a word in the bubble; tap empty space and type a new line.
  7. Force-quit, reopen → text, order, and audio all back and replayable.
